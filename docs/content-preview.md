# 实验性内容预览与拍摄

这些功能用于临时查看或替换本机显示，不会给账号增加物品。默认全部关闭，重启游戏或切换账号后会清除；与翻译开关分开控制。

## 打开功能

悬浮窗 → 详细设置 → 额外功能 → **实验性 · 内容解锁与预览**。开启需要的类别后，重新进入游戏对应页面。

| 类别 | 用法 |
| --- | --- |
| 服装、发型与发饰 | 在普通换装或拍摄页选择；普通换装中点击「确认」后，临时保留本机外观 |
| 拍摄姿势 | 在姿势列表、鉴赏和正式拍摄中查看扩展姿势 |
| 名片装饰 | 在名片背景编辑页选择并确认；该页面的背景和装饰改动只保留在本机 |

服装和发型仍需满足游戏的搭配要求。首次使用时需要下载对应资源；剧情指定的服装不受普通换装影响。

## 拍摄与模型设置

在同一页面打开 **拍摄与模型设置**，先开启「使用已有角色初始数据」，再选择下面的功能。完成后点击「应用设置」，重新进入鉴赏或拍摄。

- **运行时模型替换**：添加规则，选择原角色、显示角色及服装、发型、饰品。原角色按人物识别，不受其原先穿戴影响；可添加多条规则，也可让多个位置显示同一个角色。外观选项提供缩略图，角色按组合排列，非可玩角色集中显示。
- **显示限时 MV 与拍摄场景**：查看部分曾开放的限时内容，仍需游戏资源可下载。
- **姿势拍摄允许联动角色**：在姿势拍摄中选择联动角色。没有专用动作时会借用普通角色的动作和表情，可能出现穿模或表情不自然。

模型替换只影响实时 3D 画面，不改变预录 MV 视频。独立模型使用固定外观，不能另外选择服装、发型或饰品。

## 保存照片前请注意

**正式保存会上传照片、写入账号，并按游戏规则消耗胶卷。** 只想查看效果时，使用「鉴赏／预览」。

「使用已有角色初始数据」决定正式拍摄时如何填写角色和场景信息：

- **开启**：使用账号已有角色的初始服装、发型、姿势和表情；必要时用已开放场景代替限时场景。未持有角色会随机对应到一个未被其他位置占用的已有角色，同一次拍摄保持一致。照片保留本机画面，但服务器记录可能与画面不同。
- **关闭**：沿用游戏当前选择的信息，未持有内容可能被服务器拒绝。

这些都是实验功能，不保证服务器接受所有组合；建议仅用测试账号。它们不会免费提供胶卷或改变账号持有物品。

## 恢复与限制

- 关闭对应开关后，退出并重新进入游戏页面；重启游戏可清除全部临时设置。
- 「恢复原穿戴外观」可单独还原普通换装；「关闭全部拍摄实验功能」可清除拍摄与模型设置。已保存的照片不会因此删除或还原。
- 若要正常保存穿戴或名片设置，先关闭相应开关，再重新进入编辑页面。
- 周边和称号暂不支持。接口不兼容时，相应类别会显示不可用；离线版尚未验证。
