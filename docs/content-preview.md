# 实验性内容预览

这个功能可以在本机查看部分未持有的内容，并临时使用服装、发型、姿势或名片装饰。它不会给账号增加物品；普通换装和名片编辑的确认只改变本机显示。

## 如何使用

打开悬浮窗 → 详细设置 → 额外功能 → **实验性 · 内容解锁与预览**，开启需要的类别，再重新进入对应的游戏页面。

各项默认关闭，与翻译开关分开控制；关闭翻译不会自动关闭预览功能。

| 类别 | 可以做什么 |
| --- | --- |
| 服装 | 在普通换装页试穿，点击「确认」后临时使用该日常或演唱会外观；拍摄的服装选择页也能查看 |
| 发型与发饰 | 在普通换装或拍摄选择页查看可搭配的选项；普通换装中点击「确认」后临时使用 |
| 拍摄姿势 | 在姿势列表、「鉴赏／预览」和正式拍摄场景中使用扩展姿势 |
| 名片装饰 | 重新进入名片背景编辑页，选择装饰并确认，临时改变本机显示；该页的装饰和背景改动都不会保存到账号 |

服装与发型仍需符合游戏原有的搭配要求，剧情指定的服装不受影响。第一次查看未下载的内容时，仍需等待游戏下载模型、图片或动作资源。

## 如何恢复

这些临时修改只在本次游戏运行期间保留。关闭对应开关、切换账号或重启游戏后会还原，重新打开对应页面即可查看。也可以点击「恢复原穿戴外观」，单独清除临时选择的服装和发型。

如果想正常保存账号的穿戴或名片设置，请先关闭对应开关，再退出并重新进入编辑页面；已经打开的预览页面不会因为关掉开关就恢复账号保存功能。

## 使用限制

正式拍摄会使用当前选择的服装、发型和姿势 ID，按游戏原有流程向服务器发送请求，未持有内容可能被服务器拒绝，账号侧的处理结果尚未验证。只想查看效果时，请选择「鉴赏／预览」。

如果设置中提示「普通换装接口不可用，仅开放拍摄列表」，服装和发型就只能在拍摄选择页查看，暂时不能用于普通换装。

周边和称号暂不支持。离线版尚未验证；无法适配的类别会显示不可用。
